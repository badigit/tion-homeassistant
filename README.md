# Tion MagicAir — интеграция для Home Assistant

Бризеры Tion и станции MagicAir через облако `api2.magicair.tion.ru`.
Собственный асинхронный клиент, без внешних зависимостей.

## Что появляется в Home Assistant

Одно устройство-хаб на локацию аккаунта и по устройству на каждый бризер и
станцию. Комната подсказывается из имени зоны в облаке.

**Бризер**

| Сущность | Что показывает |
| --- | --- |
| `climate` | режим (выключен / продув / нагрев), скорость, целевая температура |
| `sensor` «Температура на входе» | воздух до бризера (`t_in`) |
| `sensor` «Температура на выходе» | воздух после бризера (`t_out`) |
| `sensor` «Скорость» | текущая скорость вентилятора |
| `sensor` «Производительность» | приток в м³/ч |
| `sensor` «Ресурс фильтра» | сколько дней фильтру осталось |
| `sensor` «Наработка» | часы работы, диагностический |
| `sensor` «Уровень сигнала» | диагностический |
| `sensor` «Код ошибки» | диагностический |
| `binary_sensor` «Вентилятор» | работает или нет |
| `binary_sensor` «Требуется замена фильтра» | ресурс исчерпан |
| `binary_sensor` «Связь» | устройство на связи с облаком |
| `number` «Минимальная/максимальная скорость в авто» | границы для автоматики зоны |
| `number` «Порог CO2» | уровень, по которому облако ведёт зону |
| `select` «Источник воздуха» | улица / помещение / смешанный — только у моделей с заслонкой |

**MagicAir**

| Сущность | Что показывает |
| --- | --- |
| `sensor` «CO2» | углекислый газ, ppm |
| `sensor` «Температура» / «Влажность» | климат комнаты |
| `sensor` «PM1» / «PM2.5» / «PM10» | пыль — только у моделей, которые её измеряют |
| `sensor` «Сигнал Wi-Fi» | диагностический |
| `binary_sensor` «Связь» | станция на связи с облаком |

Сущности, за которыми в конкретной модели нет датчика, не создаются: облако
отдаёт для них `NaN`, и интеграция это отличает от нуля.

### Скорость и режим зоны

Облако Tion управляет зоной, а не отдельным бризером. У climate-сущности
скорость `auto` означает, что зону ведёт облако по уровню CO₂; выбор
конкретной скорости или `off` переводит зону в ручной режим. Режим зоны, её
имя и порог CO₂ видны в атрибутах `zone_mode`, `zone_name`, `zone_target_co2`.

Список скоростей строится по `speed_limit` устройства: у O₂ это 1–4,
у S3/S4 — 1–6.

Порог CO₂ и границы скорости — свойства зоны, а сущности живут на бризере.
Если в одной зоне стоит несколько бризеров, их одноимённые настройки
показывают и меняют одно и то же значение.

## Устройство кода

```
aiohttp-сессия Home Assistant
        ↓
TionApiClient (api.py) — про HA ничего не знает
        ↓
TionDataUpdateCoordinator
        ↓
сущности
```

`api.py` — самостоятельный клиент: сессию получает снаружи, состояние отдаёт
дата-классами, ошибки поднимает своими типами (`TionAuthError`,
`TionConnectionError`, `TionCommandError`). Его можно дёргать из обычного
скрипта без Home Assistant.

Токен доступа лежит в `.storage/tion_magicair.<entry_id>` и переживает
перезапуск, поэтому логин не тратится на каждый старт. Протухший токен клиент
обновляет сам, ровно одна повторная попытка на запрос.

## Установка

1. Скопировать каталог `custom_components/tion_magicair` в `custom_components`
   своего Home Assistant.
2. Перезапустить Home Assistant.
3. **Настройки → Устройства и службы → Добавить интеграцию → Tion MagicAir**,
   ввести почту и пароль от аккаунта MagicAir.

Интервал опроса меняется в настройках интеграции, по умолчанию 60 секунд.

## Что проверено вживую

Аккаунт с одним бризером **Tion O₂ Rf** (`tionO2Rf`) и одной станцией
**MagicAir** (`co2mb`): чтение всех величин, смена температуры, скорости и
режима зоны.

Код для **S3, S4 и Lite** написан по протоколу, но на железе не проверялся:
у этих моделей есть заслонка и другой потолок скоростей, а у 4S — отдельная
логика нагрева. Отзывы приветствуются.
